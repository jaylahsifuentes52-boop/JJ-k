JUNIOR AI - NETLIFY PROJECT

FILES
- index.html, style.css, app.js: website interface
- netlify/functions/chat.mjs: secure server-side OpenAI request
- netlify.toml: Netlify publish and functions configuration

DEPLOY
1. Upload the contents of this folder to the root of your GitHub repository.
2. In Netlify, set the environment variable OPENAI_API_KEY to your secret API key.
3. Keep the key secret. Do not put it in app.js, index.html, or GitHub.
4. Deploy/redeploy the site.
5. Test the site by sending a message.

The API key is NOT included in this ZIP. API usage may cost money; ask a parent/guardian before adding payment details.
